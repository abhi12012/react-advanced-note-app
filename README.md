# Advanced Notes App



## Project Overview

A modern React-based notes application for creating, editing, searching, filtering, sorting, and managing notes.



## Features

- Create, edit, and delete notes
- Undo deleted notes
- Pin and unpin notes
- Search notes with text highlighting
- Filter by category, priority, and pin status
- Sort notes by priority, date, and title
- Pagination
- Form validation
- Created and updated timestamps
- Dark mode
- Empty states
- CSV import and export
- JSON import and export
- Backup and restore

## How to Use

1. Enter a title and description to create a note.
2. Select a category and priority.
3. Use the Pin button to pin important notes.
4. Use Search to find notes quickly.
5. Use filters and sorting to organize notes.
6. Use pagination to navigate through notes.
7. Export notes as CSV or JSON.
8. Import notes from CSV or JSON files.
9. Use Backup and Restore to manage note backups.
10. Toggle Dark Mode for a different appearance.



## Data Management

### CSV

- Export notes to CSV.
- Import notes from CSV.
- Supports quoted values, commas, and escaped quotes.

### JSON

- Export notes to JSON.
- Import notes from JSON.
- Create and restore note backups.
